# Task 4: Data Storytelling & Business Insights

This project focuses on presenting business insights from the Superstore dataset using data storytelling techniques.

## Objective

The objective of this task is to transform analytical findings into a clear business story that can support decision making.

## Tools Used

- Python
- SQL
- Power BI
- PowerPoint

## Presentation Overview

The presentation covers:

- Dataset overview
- Key performance indicators
- Sales performance by category
- Regional sales analysis
- Monthly sales trends
- Customer segment insights
- Key business insights and recommendations

## Key Insights

- Technology category generates the highest revenue.
- West region contributes the largest share of sales.
- Sales increase toward the end of the year indicating seasonal demand.
- Consumer segment contributes the majority of orders.

## Conclusion

Data storytelling helps convert analytical results into meaningful business insights that support better strategic decisions.
